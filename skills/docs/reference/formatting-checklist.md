# Pre-Submission Document Formatting Checklist

Review any formal report, proposal, or whitepaper against this checklist before exporting the final version.

---

## 1. Document Page & Geometry Setup
*   [ ] **Margins Policy:** Are margins set to exactly `1.0 inch` (`2.54 cm`) on all four sides?
*   [ ] **Page Numbers:** Are page numbers placed consistently at the bottom center or bottom right? (Ensure the title page has no visible page number).
*   [ ] **Header/Footer Consistency:** If headers contain the document title or section category, do they accurately match the current chapter name?
*   [ ] **Alignment Check:** Is all body text left-aligned to prevent arbitrary spacing gaps (ragged right margin layout)?

---

## 2. Heading & Typographic Hierarchy
*   [ ] **Typographic Consistency:** Are we using a maximum of two font families (one for headings, one for body text) throughout the document?
*   [ ] **Sequential Levels:** Check formatting tags sequentially. Ensure that an H3 heading is never nested directly under an H1 without a parent H2.
*   [ ] **Heading Casing:** Do all section headers follow the same capitalization standard (e.g., Sentence Case or Title Case)?
*   [ ] **No orphans:** Are there at least two rows of body copy following every heading at the bottom of a page?

---

## 3. Spacing Rhythm & Margins
*   [ ] **Spacing Settings:** Inspect spaces between paragraphs. Verify that we use dedicated paragraph style margins (`6pt` or `8pt` space-after) rather than double manual blank lines.
*   [ ] **Line Spacing:** Is line spacing set uniformly (e.g., `1.15` or `1.5`) across all body copy sections?
*   [ ] **List Indents:** Are all bulleted lists aligned at exactly `0.5 inches` (`1.27 cm`) from the left margin?

---

## 4. Citation & Referencing Integrity
*   [ ] **1:1 Mapping Verification:** Check every source in the final reference list against in-text markers. Ensure there are no unused references or uncited markers.
*   [ ] **In-Text Format:** Are all markers formatted as `(Author Surname, Year)` (or `(Author Surname and Co-Author, Year)`) placed inside sentence ending punctuation?
*   [ ] **Year Accuracy:** Do publication dates in the text match the dates listed in the Reference List?

---

## 5. Tables & Figures Verification
*   [ ] **Caption Placement:** Table captions placed *above* tables, and Figure captions placed *below* figures.
*   [ ] **Numeric Sequence:** Are captions numbered in correct chronological order (`Table 1`, `Table 2`, etc.)?
*   [ ] **Borders & Gridlines:** Are heavy gridlines stripped, leaving bold/shaded headers and subtle horizontal rules?
*   [ ] **Source Disclosures:** Does every table compiled from external metrics feature a clear source attribution line at the bottom?
*   [ ] **Alignment Mapping:** Text columns left-aligned, numbers right-aligned, and decimal places aligned.
