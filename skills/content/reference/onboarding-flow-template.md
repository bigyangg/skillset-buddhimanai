# Onboarding Flow Copy Template

Use this lightweight copy skeleton to draft walkthrough cards, banner steps, and onboarding modals.

---

## Structure Guidelines

An ideal walkthrough contains exactly 3 steps. Keep screens simple and fast to maintain onboarding momentum.

---

## Step 1: Welcome & Primary Value

Focus on the visual/functional "Aha!" moment. Do not explain navigation rules; explain what they can achieve.

```
Header:     Welcome to [App Name], [User's Name].
Body:       Let's set up your team board so you can start organizing sprints and sharing progress.
CTA:        Configure board (Primary Action)
Dismiss:    Skip setup (Standard link button placement - dismisses flow)
```

---

## Step 2: Minimum Viable Configuration

Request only the minimum parameters required to render dashboard visuals. Do not ask for full-scale configurations.

```
Header:     What's your current sprint goal?
Body:       Name your active project board to align dashboard metrics with team goals.
Form Label: Sprint board name
Placeholder: e.g. Q3 product release
CTA:        Continue (Primary Action)
Dismiss:    Skip for now (Muted button)
```

---

## Step 3: First "Aha!" Milestone

Direct the user straight into the core tool feature context.

```
Header:     Your sprint board is ready.
Body:       We've generated three backlog cards based on your template. Drag cards to "In progress" to start tracking tasks.
CTA:        Go to workspace (Primary Action)
```
